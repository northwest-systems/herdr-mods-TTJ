# App icon

チケット形の中央にTTJを配置した、512×512 px・1:1の透過PNGです。

| 用途 | PNG | 配色 |
| --- | --- | --- |
| ライト背景 | [app-icon-light.png](../mods/ttj/assets/app-icon-light.png) | 濃い緑のチケット、黄緑のTTJ・ミシン目 |
| ダーク背景・標準 | [app-icon.png](../mods/ttj/assets/app-icon.png) | 黄緑のチケット、濃い緑のTTJ・ミシン目 |
| 単色・黒 | [app-icon-black.png](../mods/ttj/assets/app-icon-black.png) | 黒、TTJ・ミシン目は透過 |
| 単色・白 | [app-icon-white.png](../mods/ttj/assets/app-icon-white.png) | 白、TTJ・ミシン目は透過 |

緑は`#166534`、黄緑は`#A3E635`です。表示先の背景に合わせてPNGを選択します。
